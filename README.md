## Project Overview
This project demonstrates QR-code-based footprinting and information gathering in a controlled cybersecurity testing environment.
It explores web-request metadata, IP-based approximate geolocation, device and browser information, and location access with user permission.

## Project Objectives
- Understand how QR codes redirect users to webpages.
- Explore web-request metadata.
- Understand IP-based approximate geolocation.
- Learn how browser permissions control access to GPS coordinates.
- Promote responsible cybersecurity testing and privacy awareness.

## Methodology
1. Generate a QR code linked to a webpage.
2. Scan the QR code using an authorized test device.
3. Observe the webpage opened by the QR code.
4. Examine available web-request metadata.
5. Test location access only with the participant's permission.
6. Document verified results while protecting personal information.

## Privacy and Ethics
Testing must be conducted with appropriate authorization and informed consent.
Do not publish real IP addresses, precise GPS coordinates, or other personally identifiable information.

## Conclusion
This project demonstrates how QR codes can be used to explore web technologies and cybersecurity footprinting. It also highlights the importance of consent, privacy, and responsible information gathering.
